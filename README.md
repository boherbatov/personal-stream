# TeleFlow Web

גרסת דפדפן סטטית של TeleFlow המבוססת על המבנה, הצבעים והיכולות של אפליקציית Android v0.4.2.

- ההתחברות מתבצעת ישירות ל-Telegram באמצעות GramJS בדפדפן.
- API ID, API Hash ו-session נשמרים רק ב-localStorage של הדפדפן. אין סודות בריפו.
- בחירת ערוץ, קטלוג וידאו/אודיו, חיפוש, מועדפים, המשך צפייה, קיבוץ סדרות ונגן.
- אירוח סטטי בלבד דרך GitHub Pages.

> מגבלת דפדפן: בגלל מגבלות MediaSource/codec וה-API של Telegram, קובץ המדיה נטען מהחשבון לדפדפן לפני הניגון. הממשק מציג התקדמות מקומית; ניגון Range אמיתי ללא הורדת הקובץ המלא אינו מובטח בכל דפדפן וקודק.
